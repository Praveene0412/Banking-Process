# 🏦 Java Console-Based Banking System

This is a simple **Java-based console banking system** that simulates core banking operations such as depositing, withdrawing, transferring money (with OTP verification), and viewing account balances. It uses object-oriented programming principles and serves as a great educational project for beginners learning Java.

---

## ✨ Features

- 🔐 **Login System** with Bank ID, Name, and Password
- 💰 **Deposit** and **Withdraw** Money with PIN Verification
- 🔄 **Money Transfer** Between Accounts (with OTP verification)
- 📱 **OTP System** for secure transactions
- 📊 **View Account Balance**
- 📁 Uses in-memory data structures (no database required)

---

## 🛠️ Technologies Used

- Java (JDK 8+)
- Java Collections (LinkedList)
- Scanner for user input
